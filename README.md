# hollowfiregames.github.io

Sitio de Hollowfire Studio, publicado con GitHub Pages en
https://hollowfiregames.github.io

| Página | Dirección |
|---|---|
| Inicio | `/` |
| Truco: privacidad (castellano) | `/truco/privacidad.html` |
| Truco: privacy (English) | `/truco/privacy.html` |

HTML y CSS estáticos, sin JavaScript (las animaciones, como la llama de la portada, son de CSS), sin fuentes ni recursos externos, sin
cookies ni rastreadores. Cada página tiene una Content-Security-Policy que solo
permite los estilos e imágenes del propio sitio.

Las imágenes pixel de la portada (la llama cuadro por cuadro y el nombre) salen del
mismo código que la presentación del juego Truco: `tools/site_art.gd` en ese repositorio.
